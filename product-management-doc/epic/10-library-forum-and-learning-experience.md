# Epic 10: Library, Forum, and Learning Experience

## Epic Intent

Drive recurring non-admin engagement through digital resources, peer learning, moderated discussion, and study-support surfaces.

## Primary Users

- Student
- Teacher
- School admin

## Current Implementation Requirements

- Library must support:
  retrieval, search, bookmark, recent items, view logging, and student reservation.
- Forum must support:
  question creation, answer creation, voting, flagging, feed retrieval, answers retrieval, mark-correct, leaderboard, teacher answer approval, and student reputation view.
- Frontend must expose:
  library page, forum page, question detail, leaderboard widget, student classroom/homework pages, teacher homework page, and study-assistant / AI learning surfaces.
- Homework retrieval and creation are supported in multiple admin/teacher/student flows.
- Learning mode / LUMINA Studio is available as a cross-role surface.

## Current Product Notes

- This epic is strategically important for weekly active usage beyond admin tasks.
- Today it appears broad and experience-led, but likely needs stronger instrumentation and consistency between content, interaction, and moderation behavior.

## Known Gaps / Stabilization Needs

- Test forum moderation and correct-answer workflows.
- Validate library interaction telemetry and bookmark/recent consistency.
- Clarify the maturity split between learning experience UI and backend-backed academic workflows.

## Success Metrics

- weekly active students
- weekly active teachers
- forum participation rate
- library interaction rate
- homework workflow completion rate
