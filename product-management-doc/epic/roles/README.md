# Role Capability Docs

These documents describe what each role can do currently based on the implemented frontend routes, navigation access, and exposed backend APIs.

## Important Notes

- These are current-state capability docs, not future-state PRDs.
- A role may have UI visibility only when the tenant subscription includes required feature flags such as `SCHOOL_OPS`, `ATTENDANCE`, or `TRANSPORT_BASE`.
- Some capabilities are shared across multiple roles, but each file is written from that role’s point of view so you can modify the flow later without searching through all epics.
