# Role: Conductor

## Role Intent

Support live trip execution with boarding, attendance-on-route, and passenger handling workflows.

## Current Access Surface

- Conductor panel
- Profile

## Current Capabilities

- Access active trip information.
- Perform boarding-related actions.
- Use boarding scan and boarding voice flows.
- Support onboard/offboard updates during trip execution.
- Access transport AI/status prompts related to current operational actions.

## Backend Capability References

- `school-operations-service`
- transport boarding and trip endpoints

## Product Constraints / Notes

- Conductor scope is operational and field-focused.
- Flow changes should optimize speed, accuracy, and resilience under realtime disruption.
