# Role: Manager

## Role Intent

Operate school workflows with broad administrative access across academics, operations, transport, communication, finance, and analytics.

## Current Access Surface

- Dashboard
- School CMS
- Routing
- Students
- Teachers
- Admissions
- Class
- Department / academic structure
- Attendance
- Examinations
- Timetable
- HR leaves
- Transport hub
- Library
- Forum
- Communication
- Billing and fees
- School analytics
- LUMINA Studio
- Profile

## Current Capabilities

- Access nearly the same school operations footprint as school admin and principal.
- Manage student-facing and academic-operational workflows.
- Use attendance, exam, timetable, transport, and communication surfaces.
- Access finance, analytics, and CMS workflows where enabled.
- Participate in HR leave management workflows.

## Product Constraints / Notes

- Current implementation treats manager as a broad school operator.
- If future separation is needed, this doc can evolve toward a more operations-heavy and less governance-heavy scope.
