# Role: Parent

## Role Intent

Help parents track children, receive communication, view transport context, and engage with school updates through a simpler family-facing surface.

## Current Access Surface

- Overview dashboard
- My children
- Messages
- LUMINA Studio
- Profile
- Transport subscriber view

## Current Capabilities

- Access parent dashboard.
- View children-related information through the family surface.
- View parent messages.
- Access transport subscriber view when enabled.
- Use AI/LUMINA parent guidance surfaces.
- Maintain general profile access.

## Backend Capability References

- `school-operations-service`
- `communication-service`
- `ai-interaction-service`

## Product Constraints / Notes

- Parent scope is intentionally narrower than school-side roles.
- Future modifications should optimize for clarity, trust, and timely updates rather than feature density.
