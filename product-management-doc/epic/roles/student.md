# Role: Student

## Role Intent

Give students visibility into their school experience across profile, classroom, timetable, attendance, homework, results, fees, notices, resources, and transport.

## Current Access Surface

- My portal dashboard
- Student profile
- Classroom
- Timetable
- Attendance
- Homework
- Results
- Assembly / notices
- Fee status
- Library
- Forum
- Transport
- LUMINA Studio

## Current Capabilities

- View personal profile.
- View classroom/workspace information.
- View timetable.
- View attendance analytics and update absence reason in student-scoped flows.
- View homework and update homework status.
- View results.
- View fee status.
- Access library and reserve resources.
- Access forum and own reputation-related surfaces.
- Use student communication and school update surfaces.
- View transport subscriber status and preferences when enabled.
- Use AI/LUMINA learner help surfaces.

## Backend Capability References

- `school-operations-service`
- `communication-service`
- `ai-interaction-service`

## Product Constraints / Notes

- Student access is visibility-heavy with lighter action flows.
- Any future changes should maintain a simple, guided experience rather than expose internal school complexity.
