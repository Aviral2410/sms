# Role: Teacher

## Role Intent

Run classroom workflows across classes, attendance, homework, marks, behaviour, notices, parent communication, and selected student/resource views.

## Current Access Surface

- Workspace dashboard
- Teacher profile
- My classes
- Attendance
- Homework
- Exams and marks
- Behaviour
- Parent communication
- Library
- Notices
- LUMINA Studio
- Students
- Student profile
- Forum
- Transport subscriber view
- HR leaves

## Current Capabilities

- Access teacher workspace and profile.
- View assigned classes and student lists.
- Mark attendance and use teacher attendance manager / marking flow.
- Create homework and marks entries.
- Record behaviour-related information.
- Use teacher-parent communication flows.
- View school announcements/notices.
- Use library and forum surfaces.
- Access student profile/detail views from the teacher workflow.
- Use “my transport” subscriber surface when transport is enabled.
- Submit or manage own leave requests through HR flows.
- Use AI/LUMINA teaching support surfaces.

## Backend Capability References

- `school-operations-service`
- `communication-service`
- `ai-interaction-service`

## Product Constraints / Notes

- Teachers currently have strong execution access but not broad school governance access.
- Future changes here should preserve fast daily workflow completion with minimal admin overhead.
